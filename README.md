# 📚 SVVV Notes Portal

A full-stack web application built using **React + Django** that provides students with easy access to **Notes, PYQs (Previous Year Questions), and study materials** in one place.

This project helps students save time by avoiding manual searching and provides a clean, organized digital platform for academic resources.

---

## 🚀 Features

✅ User friendly UI
✅ Notes download & view
✅ Previous Year Questions (PYQs)
✅ Subject-wise filtering
✅ Fast search
✅ Image/File upload support
✅ Admin panel to manage content
✅ Secure backend APIs
✅ Responsive design (mobile + desktop)

## ⚙️ How It Works

1. Admin uploads Notes/PYQs from Django Admin
2. Files stored in backend database
3. React fetches data using APIs
4. Students can:

   * View notes
   * Download files
   * Filter by subject

## 💻 Installation Guide

### Clone project

```bash
git clone <your-repo-link>
cd svvv-notes
```

### Backend Setup (Django)

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend Setup (React)

```bash
cd frontend
npm install
npm start
```
